## 🛠️ Tecnologías y Librerías Utilizadas

El desarrollo de las actividades se realiza principalmente en **Python 3.13** utilizando Jupyter Notebooks. Entre las librerías destacadas se encuentran:

* **Manipulación y Procesamiento de Datos:**
  * `pandas` / `numpy`
* **Visualización de Datos:**
  * `matplotlib` / `seaborn`
* **Machine Learning y Modelería:**
  * `scikit-learn` (Pipelines, ColumnTransformer, RandomForestRegressor, Preprocesamiento)
* **Interpretabilidad de Modelos:**
  * `permutation_importance` / `partial_dependence` / `PartialDependenceDisplay`
* **Descarga de Datasets:**
  * `kagglehub`
